# Demo Evidence Pages

Simulated incident write-ups for the **fictional** demo protocols registered by `scripts/deploy.mjs`
(ApexYield Lending, Orbit DEX V3, LiquidStake Bridge). They are served from
`raw.githubusercontent.com`, one of SentinEL's whitelisted oracle hosts, so GenLayer validators can
fetch them with `gl.nondet.web.render()` during the demo.

None of these describe real protocols, transactions, or incidents.
